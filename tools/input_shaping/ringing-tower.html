Ringing Tower Generator

Generate G-code for a ringing tower made for your printer. The frequency of the Input Shaper changes every few millimeters of height, so after printing you can look for the height where the ringing is smallest and read the best frequency from the table. No slicer or model file is needed.

    Before you print

    • Not yet tested on a printer. This G-code has not been run on a real printer yet. Start with a short test tower and check the result before you print a full one.
    • Smooth patterns need a slower speed. Sine, half sine and triangle patterns are built from many 1 mm segments. At high speed, Marlin's planner minimum segment time (M205 B, 20000 µs by default) can slow these segments down and blur the pattern. Use a lower Print speed for these patterns, or lower M205 B if your firmware allows it.
    • CoreXY. Set rotation to 45 to isolate the A and B motors. This has not been tested on CoreXY printers yet.
    • Retraction and Z-hop are simple. Each layer is one path, and the tool retracts only on long travels.

    See also: the Input Shaping Calibration Pattern, which finds resonance frequencies with a different pattern. That tool is by KimmoHop, based on work by @tombrazier (GPLv3). The Ringing Tower Generator is a new implementation.
