# G20 - Inch Units

Set units to inches. In this mode, all positions, offsets, rates, accelerations, etc., specified in G-code parameters are interpreted as inches.

:::warning
Requires `INCH_MODE_SUPPORT` to be enabled in `Configuration.h`. By default, Marlin uses millimeters.
:::

## Syntax

```gcode
G20 ; Set units to inches
```

## Usage

When `G20` is active:
- All coordinate values (X, Y, Z, E) are interpreted as inches
- Feed rates are in inches per minute
- Accelerations are in inches per second squared
- Temperatures remain in degrees (Celsius or Fahrenheit, depending on `TEMPERATURE_UNITS_SUPPORT`)

## Examples

```gcode
G20              ; Set units to inches
G1 X1.0 Y2.0 Z0.5 F100 ; Move to 1" x 2" x 0.5" at 100 in/min
G1 E0.1 F50      ; Extrude 0.1 inches at 50 in/min
```

## Switching Back to Millimeters

```gcode
G21              ; Set units to millimeters
```

## Notes

- Use `G21` (default) for millimeters or `G20` for inches.
- Temperature values are not affected by unit changes.
- Bed leveling offsets and probe coordinates are always in machine units (mm or inches, depending on `INCH_MODE_SUPPORT`).
