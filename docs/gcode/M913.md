- At least one parameter must be used.
- Setting `X`, `Y`, `Z`, or `E` will set the hybrid threshold for all motors that fall under that category that have the `_IS_TRINAMIC` flag set. See examples below.
- With `HOMING_HYBRID_THRESHOLD`, `M913 H` sets the threshold used only while homing. It is applied when homing an axis starts and restored when it ends. `M500` saves the values and `M503` reports them as `M913 H` lines.

---

When `HYBRID_THRESHOLD` is enabled, the TMC driver is switched from the quieter StealthChop to spreadCycle when the feed rate for a given stepper motor is over its `_HYBRID_THRESHOLD`.

With `HOMING_HYBRID_THRESHOLD` (which requires `HYBRID_THRESHOLD`), each axis also has a separate threshold that is used only while that axis is homing. This matters for sensorless homing with StallGuard4 (TMC2209 and TMC2240), which only detects stalls in stealthChop: a hybrid threshold below the homing feedrate makes sensorless homing fail. Set the homing threshold to 0 to stay in stealthChop, or above the homing feedrate. Use `M913 H X<mm/s> Y<mm/s> Z<mm/s>` to set it, or `M913 H` alone to report the values. The homing values are also available in the LCD menu under Configuration > Advanced > TMC Drivers > Homing Hybrid Thrs.
