# G0/G1 - Linear Move

Add a straight line movement to the planner. The `G0` and `G1` commands move the printer from its current position to a new position in a straight line.

:::tip
**Convention:** Most slicers use `G0` for rapid non-extrusion moves and `G1` for moves that include extrusion. However, on Cartesian and Delta printers, `G0` is just an alias for `G1`.
:::

## Syntax

```gcode
G0/F{feedrate} [X{X_pos}] [Y{Y_pos}] [Z{Z_pos}] [A{A_pos}] [B{B_pos}] [C{C_pos}] [U{U_pos}] [V{V_pos}] [W{W_pos}] [E{E_pos}]
```

## Parameters

| Parameter | Description | Type | Optional |
|-----------|-------------|------|----------|
| `F` | Feedrate (mm/min) | float | Yes |
| `X` | X-axis position | float | Yes |
| `Y` | Y-axis position | float | Yes |
| `Z` | Z-axis position | float | Yes |
| `A` | A-axis position (4th axis) | float | Yes |
| `B` | B-axis position (5th axis) | float | Yes |
| `C` | C-axis position (6th axis) | float | Yes |
| `U` | U-axis position (7th axis) | float | Yes |
| `V` | V-axis position (8th axis) | float | Yes |
| `W` | W-axis position (9th axis) | float | Yes |
| `E` | Extruder position | float | Yes |
| `S` | Laser power (requires `LASER_FEATURE`) | float | Yes |

{: .note }
All coordinates are interpreted according to the current positioning mode (`G90` for absolute, `G91` for relative). The `E` parameter is interpreted according to the extruder mode (`M82` for absolute, `M83` for relative).

## Examples

### Basic Movement

```gcode
G1 F1500          ; Set feedrate to 1500 mm/min
G1 X50 Y25.3 E22.4 ; Move to position while extruding 22.4mm of filament
```

### Rapid Move (No Extrusion)

```gcode
G0 F3000          ; Set rapid feedrate to 3000 mm/min
G0 X100 Y100      ; Move to X=100, Y=100 (no extrusion)
```

### Multi-Axis Move

```gcode
G1 F60 Z0.2       ; Move Z down 0.2mm at 60 mm/min
G1 X10 Y10 Z0.4   ; Move to X=10, Y=10, Z=0.4
```

### Laser Power Control

```gcode
G1 F100 S500      ; Move at 100 mm/min with 50% laser power
G1 X50 S1000      ; Continue to X=50 with 100% laser power
```

## Notes

- A single linear move may generate several smaller moves to the planner due to kinematics and bed leveling compensation.
- The feedrate set by `F` applies to all subsequent moves until changed.
- By default, coordinates are in millimeters. Use `G20` for inches or `G21` for millimeters.
- In Relative Mode (`G91`), all coordinates are interpreted as relative offsets.
- In Extruder Relative Mode (`M83`), the `E` coordinate is interpreted as relative.
