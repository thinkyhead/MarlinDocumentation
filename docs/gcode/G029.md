# G29 - Bed Leveling

Probe the bed and enable leveling compensation. G29 performs bed leveling by probing multiple points on the bed surface and creating a compensation map.

:::warning
Homing is required before bed leveling. Use [`G28`](/docs/gcode/G028.html) first to establish the machine position.
:::

## Bed Leveling Types

Marlin supports 5 different bed leveling systems, each with its own G29 behavior:

### Mesh-based Leveling

- **Mesh Bed Leveling (MBL)** - Economical interactive manual mesh-based leveling for small boards or machines without a probe
- **Auto Bed Leveling (Bilinear)** - Mesh-based bilinear leveling with or without a probe
- **Unified Bed Leveling (UBL)** - Mesh-based bilinear leveling with partial probing and many options

### Matrix-based Leveling

- **Auto Bed Leveling (Linear)** - Matrix-based Linear (least-squares) leveling
- **Auto Bed Leveling (3-Point)** - Matrix-based 3-point leveling

## Syntax

```gcode
G29 [A] [C] [D] [E] [F{point}] [I{grid_points}] [J{grid_points}] [L] [O] [P{level}] [Q] [R{point}] [S{point}] [T] [U] [V{level}] [W]
```

## Parameters

| Parameter | Description | Type | Optional |
|-----------|-------------|------|----------|
| `A` | Abort leveling procedure | flag | Yes |
| `C` | Create fake points for testing | flag | Yes |
| `D` | Dry-Run mode (probe but don't update) | flag | Yes |
| `E` | Engage/disengage probe for each sample | flag | Yes |
| `F` | Move to point before starting | int | Yes |
| `I` | Number of points along X axis | int | Yes |
| `J` | Number of points along Y axis | int | Yes |
| `L` | Leveling level (1-9) | int | Yes |
| `O` | Skip if leveling is already enabled | flag | Yes |
| `P` | Probe depth (mm) | float | Yes |
| `Q` | Query leveling state | flag | Yes |
| `R` | Move to point before starting | int | Yes |
| `S` | Move to point before starting | int | Yes |
| `T` | Enable probe temperature compensation | flag | Yes |
| `U` | UBL-specific: probe with UBL style | flag | Yes |
| `V` | Verbose level (0-4) | int | Yes |
| `W` | Warm up the bed before probing | flag | Yes |

## Examples

### Basic Bed Leveling

```gcode
G28              ; Home all axes
G29              ; Probe bed and enable leveling
```

### Custom Grid Size

```gcode
G28              ; Home all axes
G29 I4 J4        ; Probe a 4x4 grid (16 points)
```

### Dry Run (No Compensation)

```gcode
G28              ; Home all axes
G29 D            ; Probe but don't save leveling data
```

### Query Current State

```gcode
G29 Q            ; Query the current leveling state
```

## Notes

- Any arguments left out of `G29` will use your configured defaults from `Configuration.h`.
- To save time and machine wear, save your mesh to EEPROM with [`M500`](/docs/gcode/M500.html) and in your slicer's "Starting G-code" replace `G29` with `M420 S1` to enable your last-saved mesh.
- For multi-axis machines (`I_DRIVER_TYPE` defined) without implementation of inverse kinematics, bed leveling produces wrong results while the toolhead is not oriented vertical and perpendicular to the bed and must be turned off with `M420 S0`.
