# G28 - Auto Home

Home one or more printer axes to their endstop positions. When you first start up your machine it has no idea where the toolhead is positioned, so Marlin needs to use a procedure called "homing" to establish a known position.

:::tip
**Homing is required** before [`G29`](/docs/gcode/G029.html), [`M48`](/docs/gcode/M048.html), and some other procedures. If homing is needed, the LCD will blink the X, Y, Z indicators.
:::

## Syntax

```gcode
G28 [X] [Y] [Z] [A] [B] [C] [U] [V] [W] [H] [L] [O] [R{distance}]
```

## Parameters

| Parameter | Description | Type | Optional |
|-----------|-------------|------|----------|
| `X` | Home the X axis | flag | Yes |
| `Y` | Home the Y axis | flag | Yes |
| `Z` | Home the Z axis | flag | Yes |
| `A` | Home the A axis (4th axis) | flag | Yes |
| `B` | Home the B axis (5th axis) | flag | Yes |
| `C` | Home the C axis (6th axis) | flag | Yes |
| `U` | Home the U axis (7th axis) | flag | Yes |
| `V` | Home the V axis (8th axis) | flag | Yes |
| `W` | Home the W axis (9th axis) | flag | Yes |
| `H` | Hold current X/Y position during Z homing | flag | Yes |
| `L` | Restore bed leveling state after homing | bool | Yes |
| `O` | Skip homing if position is already trusted | flag | Yes |
| `R` | Raise nozzle before homing | float (mm) | Yes |

{: .note }
- By default, `G28` disables bed leveling. Follow with [`M420 S`](/docs/gcode/M420.html) to turn leveling on.
- With `ENABLE_LEVELING_AFTER_G28`, leveling will always be enabled after `G28`.
- With `RESTORE_LEVELING_AFTER_G28`, leveling is restored to whatever state it was in before `G28`.

## Examples

### Home All Axes

```gcode
G28 ; Home all axes (X, Y, Z)
```

### Home Specific Axes

```gcode
G28 X Z ; Home the X and Z axes only
G28 Y   ; Home only the Y axis
```

### Home with Safe Position

```gcode
G28 H ; Home Z while holding current X/Y position (avoids crashing into model)
```

### Home with Trust Check

```gcode
G28 O ; Home only "untrusted" axes (skip if position is already known)
```

### Raise Nozzle Before Homing

```gcode
G28 R5 ; Raise nozzle 5mm before homing (useful for clearance)
```

## How Homing Works

1. Each axis moves towards its endstop at the homing speed (`HOMING_SPEED`)
2. When the endstop triggers, Marlin records the position
3. The axis may "re-bump" at a slower speed for improved accuracy (based on `[XYZ]_HOME_BUMP_MM` and `HOMING_BUMP_DIVISOR` settings)
4. Once all requested axes are homed, the position is known and can be used for subsequent moves

## Notes

- Homing is required after power-on and after the steppers have been turned off for a period of time.
- The position can be lost if the machine is bumped or vibrated significantly.
- For Delta printers, homing establishes the top of the tower positions.
- The `H` parameter is useful when you want to home Z without moving the X/Y axes (e.g., to avoid crashing into a printed model).
