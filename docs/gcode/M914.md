notes:
- Set all `*_HOME_BUMP_MM` values to 0 for best results.
- Set the default stall thresholds with `*_STALL_SENSITIVITY`.
- |
  Compatible with TMC2130, TMC2209, and TMC2240.

  |Sensitivity|TMC2209, TMC2240|Others|
  |--|--|--|
  |LOWEST|0|+63|
  |HIGHEST|255|-64|

- TMC2209 and TMC2240 use StallGuard4, which only works in stealthChop. They home in stealthChop and the axis's chopper mode is restored afterward. With `HYBRID_THRESHOLD`, use `HOMING_HYBRID_THRESHOLD` (see `M913 H`) so the axis stays in stealthChop while homing.
- The TMC2240 formerly used StallGuard2 (-64 to 63, lower is more sensitive). If you used a TMC2240 with 2.1.3-b3 or a nightly build, retune your sensitivity values.
- With `TMC_DEBUG`, the `sg_result` row of `M122` shows the TMC2240's StallGuard4 load (0 to 510, lower means more load). Use it to tune the sensitivity.

- High sensitivity may produce false positives.
- Low sensitivity may fail to trigger.

examples:

- pre: Set the X stall sensitivity of a TMC2209 or TMC2240 (higher is more sensitive)…
  code: M914 X100

- pre: Set the stall sensitivity of the second Z stepper…
  code: M914 I1 Z90

---

Some TMC stepper drivers can detect when they bump into something that causes them to stop moving. This feature is so sensitive that it can actually take the place of traditional endstops. Use this command to set the bump sensitivity for the X, Y, Z, ... stepper drivers.

Value Ranges:
- TMC2209, TMC2240: 0 .. 255 (higher is more sensitive)
- TMC2130 and others: -64 .. +63 (lower is more sensitive)
